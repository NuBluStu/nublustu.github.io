How I work

One person, whole products.

I work across the entire stack and ship fast by pairing deep product taste with AI-native development. The Matchmaker’s voice runs on Claude with native tool use; its vision, embeddings, and taste models run on local open-source models — an architecture chosen so intimate data never leaves machines I control, and so marginal cost stays near zero.
